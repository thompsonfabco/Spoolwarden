# Spoolwarden 0.6.11

Upgrade the Hub with `sudo spoolwarden update`.

A feature and polish release after 0.6.10. It completes the Spoolwarden repository rename, adds all-browser HLS
camera live view, enables Hub voice settings for remote-connected Weigh Stations, adds an XML language catalog
with German and Russian translations, displays the Label Reader address unredacted in Settings, and resolves
Bambu Studio / Orca Slicer system preset inheritance when filenames differ from preset names.

## Hub & Web UI

- **All-browser HLS live view.** Printer camera live feeds now use `hls.js` so HLS streams play reliably across
  Chrome, Firefox, Edge, and Safari in both the Hub and web app.
- **Remote Weigh Station voice settings.** Hub Settings now controls voice and speech options for remote-connected
  Weigh Stations as well as directly attached stations, applying changes live.
- **Languages & translations.** Adds `strings/languages.xml` along with German (`de`) and Russian (`ru`)
  translations, fixing **Hub > Settings > General > Get more languages** so installed languages can be browsed
  and selected.
- **Label Reader address display.** **Hub > Settings > Label Reader** now displays the configured reader address
  in plain text instead of redacting it.
- **Analytics & UI polish.** Simplifies analytics views and polishes Hub Start, Devices, Spools, Intake, and
  Presets screens.

## Slicer Presets & Naming

- **Bambu / Orca system preset resolution.** Fixes missing-base errors (such as `Bambu Support For PA/PET @base`)
  when a preset filename differs from its JSON `"name"` field by resolving inheritance through name aliases.
- **Spoolwarden rename.** Updates repository links, updater metadata, installer scripts, Android strings, and
  documentation to Spoolwarden.
