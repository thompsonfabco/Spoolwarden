# Spoolwarden 0.6.10

Upgrade the Hub with `sudo spoolwarden update`.

A feature release after 0.6.9. It adds a post-install setup checklist, alert timestamps, configurable logging levels,
cost and waste analytics with order import, a reorder list, batch recent labels, and humidity and device-down alerts on
the Hub and in the Android app. It also expands PC Slicer Sync for multi-PC setups, Orca-only and macOS hosts, a
custom Windows installer wizard, and a standalone configuration GUI, and adds multi-photo capture, AI rejection, and
full Hub remote configuration and OTA updates for the Weigh Station and Tag Reader.

## Hub & Web UI

- **Post-install setup checklist.** A guided checklist tracks initial setup steps with **"I did this"** completion
  tracking.
- **Alert timestamps.** Alerts now display date and time stamps.
- **Configurable logging levels.** Settings lets you adjust Hub logging levels directly from the UI.
- **Cost & Waste Analytics and Order Import.** Track filament cost and waste across prints and import spool orders.
- **Reorder List & Batch Recent Labels.** View low-stock spools in a reorder list and print or manage recent labels in
  batches.
- **Network & Mobile alerts.** Adds `humidity` and `device_down` alert rules, along with alert rule controls in the
  Android app.

## PC Slicer Sync

- **Multi-PC sync & `watch` daemon.** Supports primary and secondary PC roles with a `watch` daemon for continuous
  syncing.
- **Orca-only & macOS support.** Works on macOS and on systems using Orca Slicer without Bambu Studio.
- **Custom Inno Setup installer wizard.** The Windows installer auto-detects slicer paths and presents checkboxes to
  modify or add them.
- **Standalone Windows configuration GUI.** Ships `filament-kit-sync-config.exe` with Start Menu and Desktop shortcuts.

## Weigh Station & Tag Reader

- **Weigh Station capture & AI controls.** Short-press yellow captures multiple photos, long-press yellow advances to
  AI matching, and long-press cancel/red rejects an AI match.
- **Full remote configuration & OTA updates.** Both the Weigh Station and Tag Reader can be configured and updated
  over the air from the Hub Devices tab.
- **Tag Reader base Hub API & CLI.** Tag Reader Hub API endpoints and CLI commands now work without requiring the
  `[web]` extra.
