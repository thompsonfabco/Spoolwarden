# Spoolwarden 0.6.12

Upgrade the Hub with `sudo spoolwarden update`.

A cross-client parity, updater resilience, and polish release after 0.6.11. It adds a `SHA256SUMS`-verified GitHub Releases fallback for Android updates when the Hub is unreachable, aligns features and UI across all clients, and hardens Tag Reader and Weigh Station firmware and APIs.

## Android & Updates

- **Direct GitHub Releases update fallback.** Adds a `SHA256SUMS`-verified GitHub Releases update fallback when the Hub is unreachable, alongside Android UI parity across printers, presets, corrections, alerts, search, and settings.

## Cross-Client Parity & Hub / Web UI

- **Client feature alignment.** Brings Hub Console, Mobile Web App, Android, Weigh Station, and PC Sync into alignment across spools, printers, alerts, presets, corrections, analytics, and settings.
- **Interface & localization polish.** Completes interface polish across touch targets, focus/accessibility, live status indicators, and `en`/`de`/`ru` string catalog completeness.

## Tag Reader & Weigh Station

- **Firmware & API hardening.** Refines Tag Reader firmware and API (`reader_api`, `settings`, `ota_digest`) and hardens Weigh Station authentication and voice settings.
